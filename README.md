# PING TABLET — очередь на настольный теннис

Telegram-бот для лагеря с двумя столами и общей FIFO-очередью.

## Правила
- За каждым столом одновременно играют 2 человека.
- Очередь общая для двух столов.
- Когда стол свободен, бот автоматически назначает следующих двух игроков.
- После завершения игры оба игрока освобождают стол.
- Следующая пара автоматически получает свободный стол.
- Если в очереди один человек, он ждёт следующего участника.
- Один Telegram-аккаунт может находиться только в одном месте: в очереди или за столом.

## Возможности
- Запись и выход из очереди.
- Просмотр двух столов и списка ожидания.
- Автоматическое распределение по столам.
- Уведомления игрокам о начале и завершении игры.
- Админ-панель: завершение игры, пауза, очистка ожидающей очереди.
- Команда `/remove TELEGRAM_ID` для удаления человека из очереди.
- SQLite с постоянным хранением на Railway Volume.

## 1. Создать Telegram-бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`.
3. Придумай имя и username.
4. Скопируй токен.

## 2. Узнать свой Telegram ID
Временно запусти бота без ADMIN_IDS или добавь свой ID после первого запуска.
Напиши боту `/myid`, скопируй число.

## 3. Загрузить проект в GitHub
Загрузи все файлы и папку `app` в новый репозиторий GitHub.

## 4. Развернуть на Railway
1. Создай новый проект → Deploy from GitHub Repo.
2. Выбери репозиторий.
3. В Variables добавь:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_IDS` — твой Telegram ID (можно несколько через запятую)
   - `DATABASE_PATH` — `/data/queue.db`
4. В Settings → Volumes создай Volume и установи Mount Path `/data`.
5. Запусти Deploy.

Важно: Volume нужен, чтобы очередь и активные игры сохранялись при перезапусках и деплоях.

## Команды
- `/start` — открыть очередь
- `/queue` — показать актуальную очередь
- `/myid` — показать свой Telegram ID
- `/admin` — панель администратора
- `/remove TELEGRAM_ID` — удалить человека из ожидающей очереди

## Как пользоваться
Каждый участник один раз открывает бота по ссылке и нажимает Start.
Затем нажимает «Записаться». Бот сам распределяет игроков по двум столам.
Игрок, который закончил матч, открывает бота и нажимает кнопку «Завершить игру».
Кнопка доступна участникам текущего матча и администраторам.

## Примечания
- Бот работает через личные сообщения Telegram. Участники должны хотя бы один раз нажать Start.
- Очередь общая для всех пользователей бота, даже если они открывают его в разное время.
- Для корректной работы запусти только один экземпляр бота (один Railway worker/service).
- Перед запуском проверь, что токен и ADMIN_IDS указаны без лишних пробелов.
